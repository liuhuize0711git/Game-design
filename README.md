# Game-design · 游戏合集

本仓库用于存放多个独立游戏。每个游戏都放在仓库根目录下、以游戏名称命名的独立文件夹中。

## 游戏目录

| 游戏 | 简介 | 源码与运行说明 |
| --- | --- | --- |
| 萌芽守卫 | 原创花园塔防，4 种植物、10 个递进关卡 | [萌芽守卫](./萌芽守卫/) · [运行说明](./萌芽守卫/README.md) |

## 存储约定

1. 新游戏必须在仓库根目录创建以游戏名称命名的文件夹，例如 `萌芽守卫/`，不同游戏分别存放。
2. 游戏相关的源码、素材、测试、依赖清单、锁文件、配置和说明文档都放在对应游戏文件夹中。
3. 每个游戏提供自己的 `README.md`，写明环境要求、安装、启动、构建、测试与玩法。在该游戏目录内执行相关命令。
4. 各游戏独立管理依赖和构建输出，用各自的 `.gitignore` 忽略依赖目录、生成产物和本地配置；不要提交密钥。
5. 新增游戏时，同步更新本 README 的游戏目录。仓库根目录只存放游戏文件夹以及仓库级说明或公共配置。

```text
Game-design/
├── README.md
├── 萌芽守卫/
│   ├── README.md
│   ├── package.json
│   ├── package-lock.json
│   ├── index.html
│   ├── public/
│   ├── src/
│   └── tests/
└── 其他游戏名称/
    └── 该游戏的相关文件
```

## 启动萌芽守卫

从仓库根目录执行：

```sh
cd 萌芽守卫
npm ci
npm run dev
```

测试和构建也在 `萌芽守卫/` 目录内执行：`npm test`、`npm run build`。
