# 萌芽守卫 · Sprout Guard

明亮、可爱的原创花园塔防小游戏。守护小南瓜，完成 10 个逐渐变难的关卡。使用 Canvas 2D 绘制原创地图、植物、怪物和特效，无素材下载、后端服务或 API 密钥要求。

## 运行

需要 Node.js 20.19+ 或 22.12+（当前已使用 Node.js 24 验证）。

```sh
npm ci
npm run dev
```

Vite 默认监听 `0.0.0.0:5173`。生产构建与静态预览：

```sh
npm run build
npm run preview
```

`dist/` 可部署到静态网站服务。运行 `npm test` 执行战斗引擎测试，包含 10 关完整战斗模拟；模拟使用合法收入购买、升级植物，不跳过敌人或波次。

## 玩法

- 选择植物，再点击地图上的圆形空地种植。键盘 `1`–`4` 可快速选择，`Esc` 取消。
- 点击「开始守护」或「下一波」迎敌。每波之间可以充分调整阵容。
- 消灭敌人、完成波次获得阳光；点击已种植物可升级（最多三级）或按累计花费的 70% 出售。
- 豌豆射手快速单体攻击；冰铃花减速；栗子大炮范围爆破；向日葵连锁攻击。
- 支持暂停、1× / 2× / 3× 速度、可切换的程序生成音效。空格可暂停，地图聚焦后可用方向键或 Tab 遍历种植位，Enter 种植或选中。
- 每关初始生命 20，敌人到达终点会扣血。普通敌人扣 1，甲壳虫扣 2，首领扣 5。
- 满血通关获得 3 星，剩余至少 14 点获得 2 星，其余为 1 星。通关解锁下一关；已通关关卡可以重复挑战。
- 关卡解锁与最佳星级保存在当前浏览器的 `localStorage`。刷新会重置当前战斗，但保留已完成关卡；不提供跨设备同步。
- 桌面与手机均可用；不依赖外部字体、图片或音频服务。

## 代码结构

- `src/engine.js`：关卡数据、战斗逻辑、经济、寻路、伤害与胜负状态。
- `src/render.js`：Canvas 地图、原创角色与战斗特效。
- `src/main.js`：交互、模态框、存档与声音。
- `src/style.css`：响应式界面。
- `tests/engine.test.js`：引擎与十关通关回归测试。

美术以原创植物与南瓜为主题，参考休闲塔防的明亮、可爱氛围，未使用「保卫萝卜」的商标、角色或素材。
